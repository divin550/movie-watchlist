# Movie Watchlist

A simple and interactive Movie Watchlist web application built with HTML, CSS, and JavaScript. It helps users organize their movies, keep track of what they want to watch, and manage their personal movie collection.

## Features

- **Movie Collection:** View a collection of movies with their posters, titles, genres, release years, and ratings.
- **Add Movies:** Add new movies to your collection using a form.
- **Edit Movies:** Update existing movie details without creating duplicate cards.
- **Delete Movies:** Remove movies from your watchlist.
- **Watch Status:** Mark movies as watched or to watch.
- **Favorites:** Mark your favorite movies for easy access.
- **Search Movies:** Search for movies by title.
- **Sidebar Navigation:** Browse all movies, watched movies, favorites, and movies to watch.
- **Local Storage:** Save your movie collection in the browser so your data remains available after refreshing the page.
- **Dark Theme:** A dark interface for a clean and comfortable viewing experience.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start adding and managing your movies.
